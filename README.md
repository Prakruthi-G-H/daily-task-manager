# 📋 Daily Task Manager

A simple and interactive daily task management app built using **HTML**, **CSS**, and **JavaScript**.

## 🛠️ Technologies Used

- **HTML5** — Structure and content of the web page 
- **CSS3** — Styling, layout, and animations  
- **JavaScript (ES6)** — Dynamic functionality and DOM manipulation 


## 📁 Project Structure

- `index.html` → Main frontend HTML structure  
- `TaskManager.css` →  Styling for layout and design
- `TaskManager.js`  → JavaScript logic for adding, removing, and marking tasks
- `README.md` → Project documentation

## ✨ Features

- ➕ **Add New Tasks** – Instantly add tasks using the input field  
- ✅ **Mark as Completed** – Check off tasks once they’re done  
- 🗑️ **Delete Individual Tasks** – Remove tasks with a single click  
- ⚡ **Clear All Tasks** – Quickly remove all completed or pending tasks 
- 🎨 **Modern UI Design** – Clean layout with hover animations and transitions  
- 📋 **Responsive Design** – Optimized for mobile, tablet, and desktop  
- 🔄 **Real-Time Updates** – Powered by JavaScript DOM manipulation  

## 🚀 How to Run
1. Download or clone the repository:
   ```bash
   git clone https://github.com/Prakruthi-G-H/daily-task-manager.git
   
2. Open the folder in VS Code or any code editor.
3. Open index.html in your browser or run using Live Server.
4. Start adding and managing your daily tasks instantly — no backend required.
